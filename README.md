# ASTRA·4D — 四维远征

在浏览器里运行的**四维 `(x, y, z, w)` 异星开拓游戏**。世界不是「一张随 w 变化的高度贴图」，而是一个固定的四维标量场 `F(X,Y,Z,W)`：四个分量全部参与噪声演算，地表是沿 Y 求 `F=0` 得到的等值面。`w` 是贯穿七颗行星的**连续世界线**，滑过它时地形、天空、重力、矿脉连续过渡，不再瞬移换行星。

> **[▶ 在线试玩](https://jerrygriffin.github.io/astra-4d/)** · 打开浏览器就能玩，电脑与手机都适配
>
> 当前版本 **1.1.1**（2026-11-12，四维演算重做 + 缓存兜底），改动记录见 [CHANGELOG.md](CHANGELOG.md)。

## 玩法

**移动与相机**：`W A S D` 移动 · `Shift` 疾跑 · `空格` 跳跃 · 拖拽转视角 · 滚轮/双指缩放。陡坡减速 55%
**世界线 W**：`Q / E` 连续滑移（范围 `0~6`，七个整数锚点 = 七颗行星）；也可拖动左下**世界线轨道**、点击星球、按 `1–7` 设定航线。滑移会真实经过中间每一颗行星，天空 / 雾 / 重力 / 资源表逐帧插值
**四维场**：`G` 打开四维场面板，查看 `F(X,Y,Z,W)` 的 XZ / YW / ZW 真实密度切片、等值面与实时残差；拖动面板里的 W 滑块会真实移动你。旧版「转换空间视图」（重排噪声槽位）已移除——那不是四维演算
**地形**：山脊、峡谷、台地、沙丘、径向陨石坑都由同一个场生成；陡坡露岩、高处亮色、洼地压暗。右下角有等高线小地图与沿视线剖面图
**地形工具**：按住 `左键` 挖（或填），`R` 切换挖/填。挖出的土进土壤罐，填土消耗土壤
**找矿**：矿脉是同色矿块堆成的小丘，浅层露头、深层埋在 1~4 米土里；挖到会一块块崩进背包。矿脉与装饰一次性散布在整个世界线里，滑 w 只改变可见窗口
**新玩法**：两颗行星之间的过渡带（`w = i + 0.5`）长出**相位结晶**（研究舱 900 字节）；`X` **相位扫描** 9 秒标出附近矿脉；`K` **里程碑** 13 项目标（七行星 / 登顶 / 贯穿世界线 / 建造等）自动奖励字节
**破碎链**：破碎机 2 矿→3 碎矿，洗矿机 3 碎矿 + 1 化合物→4 纯净矿，全链每矿产 **2 份金属**，概率副产稀有粉
**世界线辐射带**：`w > 4.7` 起辐射强度连续上升，高阶矿只在这里出现；先造**相位防护服**再去
**电压档**：机器分 LV / MV / HV，电网电压看最高档电源；LV 电网带不动 MV 机器（降到 25% 速度）
**遗址**：地表散落废弃前哨、探测者残骸与星门碎片，`F` 搜刮补给箱与数据核心
**建造**：`B` 背包 · `C` 建造 · `V` 研究 · `J` 图鉴 · `1–7` 星图 · `K` 里程碑 · `G` 四维场 · `X` 扫描 · `M` 联机 · `F` 交互 · `T` 系绳 · `H` 帮助
**联机**：`M` 打开 HTTP 轮询房间（4 位房号），共享位置 / 世界线坐标 / 聊天；需本地跑 `node coop-server.mjs`
**手机**：左下虚拟摇杆，右下行动键，右侧 `4D 场 / W±`；单指转视角、双指缩放；世界线与小地图保留，其余仪表压缩

核心循环：**滑世界线找矿 → 挖 / 采 → 熔炼合成 → 研究换字节 → 解锁蓝图 → 打印模块 → 接电网供氧 → 开车跑图 → 通往下一颗行星**。

## 联机（Co-op，最多 6 人）

游戏本身仍是纯静态站点；联机需要一个零依赖的本地服务（同端口既托管页面也提供房间接口）：

```bash
node coop-server.mjs          # 默认 8787，PORT=9000 可改
# 然后所有人浏览器打开 http://<你的IP>:8787/
```

- 房主在 **M 联机面板**点「创建房间」拿到 4 位房号，队友填房号加入。
- 通信是 **每 150ms 一次 HTTP 轮询**（参考 borderops 的做法，不用 WebSocket），面板会显示当前同步延迟。
- 共享：位置、朝向、行星、空间视图、相位 `w`、血量氧气、无线电聊天；远端队友渲染成同款宇航员（颜色光环 + 名牌）。
- **不共享**：地形编辑、基地模块、背包、研究进度——各自本地存档，避免互相覆盖。房主世界种子不同时会提示。
- **环境限制**：GitHub Pages 不能跑 Node，所以线上版只能单机；联机请用 `coop-server.mjs`（本机或局域网）。

## 技术说明

- **纯原生 HTML / CSS / JavaScript，零构建、零依赖、单机零运行时网络请求**。经典 `<script>` 加载（非 ES module），因此可以直接双击 `index.html`，也可以丢到任意静态服务器 / GitHub Pages。联机是可选模块：`js/net.js` 只在点「创建/加入房间」后才发请求，`coop-server.mjs` 是独立的零依赖 Node 脚本。
- 目录即模块，全部挂在 `window.A` 上：

```text
index.html            # 标题幕 / HUD / 面板骨架（静态引用版本串在这里）
style.css             # 视觉系统 + 移动端布局
js/lib.js             # 数学（四维噪声）、行星表（含深层矿带）、调色板、WebAudio 小音效
js/data.js            # 72 种物品、熔炼/破碎/洗矿/合成/大气表、33 条蓝图配方、电压与辐射常量
js/world.js           # 地形网格、编辑层、装饰、矿脉（含深层相位带）、研究样本、风暴
js/ruins.js           # 遗址：废弃前哨 / 探测者残骸 / 星门碎片与搜刮
js/build.js           # 模块外形与运行时、电网求解（电压档/熔断）、供氧传播、作业队列
js/player.js          # 宇航员、相机、地形工具、采集、系绳桩、辐射、载具驾驶
js/ui.js              # HUD 刷新、背包/建造/研究/模块/星图/图鉴/联机面板
js/net.js             # 联机客户端：150ms HTTP 轮询、远端宇航员与名牌、聊天
js/main.js            # 渲染器、天空、光照、输入、放置、存档、主循环
coop-server.mjs       # 零依赖联机房间服务（同端口托管静态站 + /api/*，开发与局域网用）
bump-version.mjs      # 版本串同步 / 缓存击穿（Node，零依赖，不参与运行）
tools/smoke.mjs       # 无头 Chromium + CDP 冒烟测试（开发用，不参与运行）
fonts/                # 本地 Outfit / Space Mono
vendor/three.min.js   # Three.js（MIT，全局 THREE）
```

- 地形性能：粗晶格缓存 + `|Δw|` 早退；挖土时只重写顶点/颜色（不重算粗晶格、不算法线，`flatShading` 走屏幕空间导数）；幽灵层低分辨率独立更新。
- 四维编辑层：`ED_CELL = 1.3`、相位桶宽 `1.0`，读写都做跨桶插值，所以地形改动在 `w` 上连续——这也是「在 `w=0` 挖的坑滑到 `w≈2` 会淡出」的原因，属于设计而非缺陷。
- 材质用 `MeshPhongMaterial + flatShading`（vendor 里这版 Three.js 的 Lambert 不支持平面着色）。
- 改完代码后先写 `CHANGELOG.md`，再 `node bump-version.mjs <新版本>` 统一升版，击穿浏览器缓存。

## 本地运行

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

推荐 Chrome / Edge / Safari 等支持 WebGL 的现代浏览器。

冒烟测试（需本机 Chrome 与可连的 CDP 端口 9222）：

```bash
node coop-server.mjs &
# 另开终端（内部脚本在 _incoming/）：
node _smoke_090.mjs      # 联机回归 16 项
node _probe_100.mjs      # 稳定性探测 12 项（随机输入 / 变图 / 死亡 / 存档）
```
