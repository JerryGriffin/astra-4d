# ASTRA·4D — 四维远征

在浏览器里运行的**四维 `(x, y, z, w)` 异星开拓游戏**：在 ASTRONEER 的循环（挖地形、采资源、熔炼合成、研究换字节、打印模块、搭电网与氧气网络、开车换行星）之上，加了一条连续相位轴 `w`——地形、矿脉、系绳全是 `w` 的连续函数，滑移时整颗行星会像呼吸一样变形。

> **[▶ 在线试玩](https://jerrygriffin.github.io/astra-4d/)** · 打开浏览器就能玩，电脑与手机都适配
>
> 当前版本 **0.8.0**（2026-11-11），改动记录见 [CHANGELOG.md](CHANGELOG.md)。

## 玩法

**移动与相机**：`W A S D` 移动 · `Shift` 疾跑 · `空格` 跳跃 · 拖拽转视角 · 滚轮/双指缩放
**四维**：`Q / E` 沿相位轴连续滑移（范围 ±6.5）。矿脉只在相位对齐时可见可采，画面会给提示
**转换空间视图**：`G`（或右上角按钮）在 `XYZ / XYW / YZW / XZW` 四个三维切片之间循环——视图名的三个字母就是当前这片三维的坐标（第一个是地面横向、第二个是高度、第三个是地面纵向），**被切掉的那一根自动变成相位轴**，所以 `XYZ` 时滑的是 `W`，`XYW` 时滑的是 `Z`，依此类推
**地形工具**：按住 `左键` 挖（或填），`R` 切换挖/填。挖出的土进土壤罐，填土消耗土壤
**找矿**：矿脉是同色矿块堆成的小丘，浅层的露头就能看见，深层的埋在 1~4 米土里——挖开才见；挖到矿脉会一块块崩进背包
**破碎链**：破碎机把 2 份金属矿粉碎成 3 份碎矿，洗矿机再用 3 份碎矿 + 1 份化合物洗成 4 份纯净矿——全链每矿产出 **2 份金属**（直炼的两倍），并概率副产镍/钴/镓等稀有粉
**深层相位**：滑到 `|w| > 4.5` 会进入深层相位带——高阶矿（星辉矿/榍石/锂）只在这里出现；同时**相位辐射**让氧气消耗翻倍、持续掉血，先造**相位防护服**再去
**电压档**：机器分 LV / MV / HV，电网电压看最高档电源；LV 电网带不动 MV 机器（降到 25% 速度），升级要拿镍钢/镁铝合金/进阶电路板造中压太阳能与中压电池
**遗址**：地表散落废弃前哨、探测者残骸与星门碎片，`F` 搜刮补给箱与数据核心（碎料 / 精炼资源 / 字节）
**建造**：`B` 背包（含随身打印机）· `C` 建造目录 · `V` 研究 · `F` 交互/上下车 · `T` 放系绳桩 · `G` 转换空间视图 · `H` 帮助
**手机**：左下虚拟摇杆，右下「行动/跳/挖填/系绳/交互」，右侧自上而下是视图键与 `相位 ±` 键（轴名随视图变化），单指转视角、双指缩放

核心循环：**挖 → 采 → 熔炼/合成 → 研究换字节 → 解锁蓝图 → 打印模块 → 接电网供氧 → 开车跑图 → 穿梭机换行星**。

## 系统一览

| 系统 | 实现要点 |
| --- | --- |
| 四维地形 | `hash4 / quintic / noise4 / fbm4` → `baseHeight(x,z,w)`，主切片 + 两层相位幽灵地形；编辑层按 `(x,z,w)` 桶存增量，挖开的坑随相位连续淡出 |
| 空间视图 | `A.slice4(u,v,p,k)` 按视图把地面两轴与相位摆进四维噪声的四个槽位，被切掉的轴当相位：`XYZ→W`、`XYW→Z`、`YZW→X`、`XZW→Y`；切换时重建地形并重新锚定矿脉，视图随存档保存 |
| 地形工具 | 球形变形写入编辑层，半径 2.2（挖填），土壤罐 12/只，挖出的土可填回去或离心成资源 |
| 七颗行星 | 希尔瓦/德索罗/卡利多/弗沙尼亚/诺福斯/格拉西欧/阿特洛克斯：地形参数、配色、日照、风力、重力、大气、资源权重各不相同 |
| 资源 | 72 种：天然 15 + 精炼 9 + 复合 19 + 气体 6 + 粉尘链 18 + 特殊 5；矿脉按 Astroneer 的做法做成 3~7 块矿堆，38% 露头、62% 埋深 1~4.1 米，每处 2~5 单位；另有 **22% 矿量只存在于深层相位**（|w|>4.5，高阶矿，约一半露头） |
| 遗址 | 每颗行星 11 处（手机 7）：废弃前哨 / 探测者残骸 / 星门碎片，各带补给箱与数据核心，`F` 搜刮，状态写进存档 |
| 加工 | 熔炉 21 条（天然 / 碎矿 / 纯净矿）、破碎机（2 矿→3 碎矿）、洗矿机（3 碎矿→4 纯净矿，全链 2 倍）、化学实验室 19 条（含 4 合金 / 2 级电路 / 磁体，部分需气体）、大气冷凝（按行星大气表）、土壤离心机 |
| 研究 | 研究舱把样本换成字节，26 个付费蓝图；地表散落 16 个研究样本 |
| 打印 | 背包打印机 / 小型打印机 / 中型打印机，共 33 条配方（26 个付费蓝图）；建造面板按「建造 / 加工」分段 |
| 电网 | 13 米内自动接线；太阳能×日照×行星系数、风力×风速×行星系数、烧碳、同位素发电机；**电压档 LV/MV/HV：电网电压=最高档电源，机器额定电压高于电网时降到 25% 速度**；电池储电与型号放电上限（1/2/8/20A）；**超载 2 秒烧熔断器，全网停机 12 秒** |
| 相位辐射 | `|w| > 4.5` 无防护：氧气消耗 ×2、离网每秒 -3 HP；氧气管网内安全；相位防护服（进阶电路板 + 硬质合金 + 石墨烯）完全免疫 |
| 氧气 | 庇护所 + 制氧机 + 系绳桩链式传播，上限 80 根；相位不匹配的系绳不导通 |
| 载具 | 漫游车（驾驶/车轮/扬尘）、穿梭机（星图往返，各行星基地独立存档） |
| 生存 | 氧气归零后掉血、死亡回最近系绳桩、沙尘风暴按行星周期来袭（庇护所可挡） |
| 存档 | `localStorage` 键 `astra4d.save.v2`，20 秒自动存 + 切页/换行星存 |

## 技术说明

- **纯原生 HTML / CSS / JavaScript，零构建、零依赖、单机零运行时网络请求**。经典 `<script>` 加载（非 ES module），因此可以直接双击 `index.html`，也可以丢到任意静态服务器 / GitHub Pages。联机是可选模块：`js/net.js` 只在点「创建/加入房间」后才发请求，`coop-server.mjs` 是独立的零依赖 Node 脚本。
- 目录即模块，全部挂在 `window.A` 上：

```text
index.html            # 标题幕 / HUD / 面板骨架（静态引用版本串在这里）
style.css             # 视觉系统 + 移动端布局
js/lib.js             # 数学（四维噪声）、行星表（含深层矿带）、调色板、WebAudio 小音效
js/data.js            # 72 种物品、熔炼/破碎/洗矿/合成/大气表、33 条蓝图配方、电压与辐射常量
js/world.js           # 地形网格、编辑层、装饰、矿脉（含深层相位带）、研究样本、风暴
js/ruins.js           # 遗址：废弃前哨 / 探测者残骸 / 星门碎片与搜刮
js/build.js           # 模块外形与运行时、电网求解（电压档/熔断）、供氧传播、作业队列
js/player.js          # 宇航员、相机、地形工具、采集、系绳桩、辐射、载具驾驶
js/ui.js              # HUD 刷新、背包/建造/研究/模块/星图/图鉴/联机面板
js/net.js             # 联机客户端：150ms HTTP 轮询、远端宇航员与名牌、聊天
js/main.js            # 渲染器、天空、光照、输入、放置、存档、主循环
coop-server.mjs       # 零依赖联机房间服务（同端口托管静态站 + /api/*，开发与局域网用）
bump-version.mjs      # 版本串同步 / 缓存击穿（Node，零依赖，不参与运行）
tools/smoke.mjs       # 无头 Chromium + CDP 冒烟测试（开发用，不参与运行）
fonts/                # 本地 Outfit / Space Mono
vendor/three.min.js   # Three.js（MIT，全局 THREE）
```

- 地形性能：粗晶格缓存 + `|Δw|` 早退；挖土时只重写顶点/颜色（不重算粗晶格、不算法线，`flatShading` 走屏幕空间导数）；幽灵层低分辨率独立更新。
- 四维编辑层：`ED_CELL = 1.3`、相位桶宽 `1.0`，读写都做跨桶插值，所以地形改动在 `w` 上连续——这也是「在 `w=0` 挖的坑滑到 `w≈2` 会淡出」的原因，属于设计而非缺陷。
- 材质用 `MeshPhongMaterial + flatShading`（vendor 里这版 Three.js 的 Lambert 不支持平面着色）。
- 改完代码后先写 `CHANGELOG.md`，再 `node bump-version.mjs <新版本>` 统一升版，击穿浏览器缓存。

## 本地运行

```bash
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

推荐 Chrome / Edge / Safari 等支持 WebGL 的现代浏览器。

冒烟测试（需要本机有 Playwright 的 Chromium）：

```bash
node tools/smoke.mjs http://127.0.0.1:8765/ ./tools/out
```
